# Cucumber Selenium Login Automation Framework

A complete **Cucumber BDD + Selenium WebDriver (Java)** automation framework  
created to test login functionality of:  
🔗 https://the-internet.herokuapp.com/login

---

## 🚀 Features
- Cucumber BDD Framework  
- Selenium WebDriver  
- Page Object Model (POM)  
- Hooks (Before/After)  
- Maven project structure  
- HTML test reports  
- WebDriverManager integration  
- Test Scenarios:
  - Valid Login
  - Invalid Login
  - Empty Fields

---

## 🧱 Project Structure

cucumber-selenium-login
├── pom.xml
├── src
│ ├── main/java/com/example/pages
│ └── test/java/com/example/stepdefs
└── src/test/resources/features/login.feature

---

## 🛠️ Technologies Used
- Java 11+
- Selenium WebDriver
- Cucumber BDD
- JUnit
- Maven
- WebDriverManager
- Eclipse/IntelliJ

---

## ▶️ How to Run the Project

### Using Maven:
mvn clean test

### Using IDE:
Right-click `TestRunner.java` → **Run As → JUnit Test**

---

## 📁 Reports
After execution, the Cucumber HTML report appears in:
target/cucumber-reports.html
